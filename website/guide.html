The NoRefund user guide

What it is The screens Tokenizers and downloads

What NoRefund actually is

NoRefund is a small desktop application you run on your own computer. Give it a PDF, a Word file, a PowerPoint deck, or a plain text file, and it tells you three things against a real AI model of your choice: exactly how many tokens that file contains, whether the file fits inside that model's context window, and roughly what it would cost to send through that model's API.

Every model counts tokens in its own way. GPT counts differently from Claude, which counts differently from Gemini. NoRefund uses each model's real tokenizer, or the closest public equivalent when a company keeps its exact one private, so the numbers you see are close to what you would actually be billed for, not a rough guess typed into a spreadsheet.

About privacy

Your files are read and counted entirely on your own machine. Nothing is uploaded, ever, while you are analyzing a document. The only time NoRefund talks to the internet is when you choose to download a tokenizer file, and that is covered later in this guide.

A tour of the screens

The left sidebar has six screens split into two groups, Tools and Data, plus a Settings screen opened from the gear icon in the top right corner of the window.

Tools

Token Calculator

The quickest screen for a "what if" question. No real file is needed here. Type in a token count by hand, pick a model from the dropdown, and NoRefund instantly shows the context window usage as a bar, whether it fits in one call, and the input, output, and total cost. Good for a fast estimate when you already roughly know how big your text is.

Tools

File Parser

The main screen for real files. Click Add File or Add Folder to bring in one or more documents (PDF, Word, PowerPoint, plain text, Markdown, Python, and JSON files are all supported), pick a model, and click Analyze. NoRefund reads every file and fills a table with the token count, how much of the context window it uses, whether it fits, how many separate API calls it would take if it does not fit in one, the estimated cost, and basic word and character counts. Results export to CSV or Markdown, and a Logs tab shows what happened if anything went wrong.

Tools

Compare Models

Paste text directly, or pick a file or folder the same way as in the Parser screen. Tick as many models as needed in the Models list, click Compare, and NoRefund runs the same document through every one of them and lines the results up, cheapest first, with the winner highlighted. This is the screen for choosing between providers, not just checking one.

Tools

Self-Host Fit Check

For open-weight models you would run yourself rather than call over an API. Pick a model architecture and a piece of hardware (a GPU, an Apple Silicon Mac, or a cloud instance), set the quantization, KV cache precision, context length, and concurrency, and NoRefund estimates whether it actually fits: a memory breakdown of weights, KV cache, activations, and framework overhead, plus how many concurrent requests the hardware can realistically serve.

Data

Model Registry

A read only reference list of every model NoRefund knows about, across seven providers at the moment (OpenAI, Anthropic, Google, DeepSeek, Meta, Mistral, and Qwen), including open-weight models you would self-host rather than call over an API. Each card shows the context window size, the input and output price per million tokens, and a link to that provider's own pricing page to double check the numbers. Use the pills at the top to filter by provider.

Data

Resources

This is where the actual tokenizer files live on disk, and the only screen where NoRefund is ever allowed to reach the internet. It gets a full walkthrough in the next section, since it is the part every new tester should understand first.

Anywhere

Settings

Click the gear icon in the top right corner from any screen to open this. Here you can set your default currency (USD, EUR, GBP, or INR), the default output token estimate the Calculator starts from, turn chunk warnings on or off, and paste a HuggingFace access token, which some tokenizer downloads need. More on that token in the next section.

Tokenizers, and how to download them

This is the part every new tester should read once before clicking around, because it explains a message you will very likely see the first time you try to analyze a file.

A tokenizer is the small piece of logic that turns your text into the exact list of numbers a model reads and gets billed for. Every model family has its own, and NoRefund uses two kinds of them.

tiktokenOpenAI's own tokenizer library, used directly for GPT models. Small and fast.
HuggingFaceUsed as a close public stand in for Anthropic and Google models, since those companies do not publish their exact tokenizer (you will see "approx." next to those model names for this reason). DeepSeek, Meta, Mistral, and Qwen publish real ones, so those are exact, not approximated.

Here is the part that matters most. The first time you analyze a file against a model, NoRefund needs that model's tokenizer file to already be sitting on your computer. If it is not there yet, NoRefund will never silently reach out and fetch it on its own. Instead it stops and tells you exactly what to do:

Once that is done, the same model works instantly every time after, even with no internet connection at all.

Downloading a tokenizer, step by step

  1. Click Resources in the left sidebar, under Data.
  2. Each row is one tokenizer. The small dot on the left tells you its status. filled means it is already downloaded. grey means it is not, yet.
  3. Find the row you need and click Download on the right. A progress bar appears while it downloads, and you can click Cancel at any point if you change your mind.
  4. Once it finishes, the dot turns filled, the file size and the folder it was saved to appear under the name, and the button changes to Open folder if you want to look at the file yourself.
  5. In a hurry? Click Download all near the top of the screen and NoRefund fetches everything that is missing in one go.

A gated model you may run into

One row you may notice, meta-llama/Meta-Llama-3-8B, is marked "Gated repo, requires a HuggingFace account or token to download." Meta requires a free HuggingFace account and their terms accepted before anyone can download that particular tokenizer. Here is how to get past it.

  1. Create a free account at huggingface.co if needed, and generate an access token from your account settings there.
  2. In NoRefund, click the gear icon in the top right corner to open Settings.
  3. Paste the token into the API tokens and secrets box and click Save. It is stored in your operating system's own secure keychain, never written to disk as plain text, and used only for this purpose.
  4. Go back to Resources and click Download again. It works now.

Worth remembering: this Download button, and this button alone, is the only place in the whole app where NoRefund reaches out to the internet. Opening a file, counting its tokens, working out the cost, and comparing models all happen entirely on your own machine, every time.

The best way to get a feel for it is to grab a document you already have lying around, drop it into the File Parser screen, and see what comes back. If a tokenizer is not downloaded yet, the app will tell you exactly what to click next, so there is nothing to get stuck on.
